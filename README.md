# AirPulse 🌍

### Machine Learning-Based Air Quality Prediction

AirPulse is a machine learning project that analyzes historical air quality data and predicts air quality using machine learning techniques.

## Objectives

* Analyze and visualize air quality data
* Clean and preprocess the dataset
* Train machine learning models
* Compare model performance using evaluation metrics
* Build an interactive prediction interface using Streamlit

## Models Used

* Linear Regression
* KNN Regression

## Evaluation Metrics

* MAE
* MSE
* RMSE
* R² Score

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Streamlit
* Jupyter Notebook

## How to Run

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. Run the Streamlit App

```bash
streamlit run app.py
```
